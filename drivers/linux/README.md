# Linux native runtime — V1

The Linux runtime is built directly from `drivers/linux/source/`. Native executables and packages are generated by the build.

## Build

```bash
bash BUILD.sh --clean
```

Generated runtime:

```text
dist/<architecture>/
```

Required build facilities include CMake, a C++17 compiler, pkg-config, libusb-1.0 >= 1.0.18 development headers, ALSA development headers and libjpeg development headers.

## Install

Interactive control panel (builds first automatically if `dist/<architecture>` is absent):

```bash
bash INSTALL.sh
```

Explicit staged path:

```bash
bash BUILD.sh --clean
sudo bash INSTALL.sh --direct
```

`BUILD.sh` installs missing build dependencies on supported package managers, downloads/validates the pinned Runtime v1.8 firmware payload and compiles the distribution. It writes a timestamped log under `drivers/linux/logs/` and keeps an interactive build terminal open at the end; `--no-pause` disables the prompt for automation. `INSTALL.sh --direct` installs runtime dependencies and the already-generated distribution, then applies the detected 1414/1473 ownership policy.

## Debian package

```bash
bash packages/build-deb.sh amd64
```

The package builder performs a fresh compile and then creates `packages/output/kinect360-remold_1.0-1_amd64.deb`. The output directory is generated and is not committed to the repository.

## RPM

`packages/rpm/kinect360-remold.spec` compiles the current source in its `%build` stage and installs from that build.

## Runtime architecture

The camera/depth, motor/control and 02AD audio-boot backends talk directly to Kinect 1414/1473 through `libusb-1.0` over Linux `usbfs`, with udev providing permissions/hot-plug policy. After UACFirmware is launched, the native `02BB/02C3` USB Audio interface remains on `snd-usb-audio`/ALSA.

The camera runtime enumerates multiple Kinects and publishes a stable manifest plus one Unix socket per physical device. RGB and Depth can fan out to multiple consumers. The optional RGB-HQ stream exposes 1280×1024 GRBG Bayer keyframes while an HQ Scanner client requests it.

See `../../docs/linux/DRIVER-RUNTIME.md` and `../../docs/BUILD-DRIVERS.md`.
