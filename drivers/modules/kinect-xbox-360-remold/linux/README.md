# Kinect Xbox 360 Remold — Linux

### Native Linux runtime for models 1414, 1473 and Kinect for Windows 1517

[Driver modules](../../../README.md) · [Linux runtime](../../../../docs/linux/RUNTIME.md) · [Build](../../../../docs/BUILD-DRIVERS.md)

**by Douglas Santana - @spidoug**


Build from the repository root with `bash Kinect-Remold.sh`. The build stage resolves dependencies, firmware and the kernel-specific virtual-camera module, then publishes the complete native runtime to `binaries/linux/drivers/kinect-xbox-360-remold/`. The generated `INSTALL.sh` performs only offline installation of that prepared bundle.

The generated driver bundle uses `bin/`, `libexec/kinect360-remold/` and `support/`; installation maps those files into the normal system `/usr` and `/etc` locations.

The runtime uses per-Kinect camera, audio, audio-control and virtual-camera endpoints keyed by stable physical `deviceId`. The resident Broker owns both `/run/kinect360-remold/control.sock` and `/run/kinect360-remold/sdk.sock`.

No package-manager package is generated by this repository.

## Hardware model routing

The runtime has separate hardware profiles:

- **Kinect 1414:** camera `045E:02AE` with `bcdDevice 0x010B`; motor/LED/accelerometer use dedicated `045E:02B0`. Runtime `02BB/02C3` is audio only for motor classification.
- **Kinect 1473:** camera `045E:02AE` with newer `bcdDevice` (known Xbox value `0x0205`); `045E:02C2` remains an untouched parent hub; motor/LED/accelerometer use `02BB/02C3 MI_00`, while microphone capture stays on the UAC audio interface through ALSA.
- **Kinect for Windows 1517:** camera `045E:02BF`; dedicated `045E:02C2` motor/LED/accelerometer control uses the classic first-generation protocol; factory `045E:02BE` USB Audio is captured through ALSA without the 02AD firmware transition.
- **Common LED behavior:** `off`, `green`, `red`, `blink-green`. Camera/control preparation initializes supported first-generation models to solid green once per fresh physical session.

Do not use an audio PID alone to decide the model; model selection is anchored to the camera descriptor and physical USB identity.
